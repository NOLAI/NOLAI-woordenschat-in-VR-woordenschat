Dit project bevat twee onderdelen: het Unity project en het dashboard project.
Het Unity project dient gebuild te worden met het IP adres van de computer waar het dashboard op draait en vervolgens op een Meta Quest geinstalleerd te worden.

Alle onderdelen geschreven en ontworpen door het Virtual Reality Learning Lab vallen onder de MIT licentie. Echter zijn er in dit project ivm tijdsrestricties modellen, materialen, animaties en andere assets gebruikt uit de Unity Asset Store. Deze zijn te vinden onder de 3rd-party map in de Assets map.
Voor een correcte werking dient elk van de assets toegevoegd te worden aan de 3rd-party map en dien je een licantie voor jouw team aan te schaffen in de Unity Store:
